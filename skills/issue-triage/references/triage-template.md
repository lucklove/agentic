# Issue Triage Template

Use this template when drafting a first-pass triage response in a Gitea issue.

```markdown
Type
- <bug | feature | question | ops | maintenance>

What is known
- <fact from issue body, comments, or directly read related context>
- <fact from issue body, comments, or directly read related context>

What is missing
- <missing detail and why it matters>
- <missing detail and why it matters>

Suspected scope
- <likely subsystem / workflow / file area>
- <say "tentative" if this is only a hypothesis>

Recommended next step
- <request info / investigate / plan / implement / answer directly / monitor>

Suggested follow-up questions
- <specific question>
- <specific question>
```

Checklist:
- Keep facts and hypotheses separate.
- Name missing context precisely.
- Prefer concrete next actions over vague statements.
- Do not claim a root cause unless you verified it.
