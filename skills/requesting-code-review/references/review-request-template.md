# Review Request Template

Use this template when posting a reviewer-facing handoff in a Gitea issue or PR
comment after implementation work is complete.

```markdown
Goal / original issue
- 

What changed
- 

Files / modules touched
- ``: 

Verification performed
- 
- Not run: 

Risks / follow-ups
- None identified beyond normal review scope.

Reviewer focus
- 
```
```

Tips:
- Replace empty bullets with concrete facts before posting.
- Remove `Not run:` if every relevant check was completed.
- If there is a real limitation or follow-up, replace the default risk line with
  the actual note.
- Keep the final comment short enough that a reviewer can scan it before opening
  the diff.
