# Plan Template

Use this template when replying in an issue or PR thread with an implementation
plan.

```markdown
Goal
- <one or two bullets describing the intended outcome>

Constraints / assumptions
- <confirmed constraint>
- <assumption or missing context>

Proposed approach
- <medium-level implementation direction>
- <how the main pieces fit together>

Task breakdown
1. <step 1: what to change, where, and why>
2. <step 2: what to change, where, and why>
3. <step 3: validation, rollout, or follow-up>

Risks
- <main risk or dependency>
- <secondary risk or unknown>

Verification
- <tests, checks, or manual validation>
- <anything that still needs confirmation>
```

Checklist:
- The tasks are small enough to execute without extra decomposition.
- File or module references were confirmed before naming them.
- Risks and verification are present.
- The plan is suitable for a Gitea issue or PR comment.
